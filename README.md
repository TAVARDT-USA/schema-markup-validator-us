# Schema Markup and Structured Data Validator

[![Schema Validator](https://img.shields.io/badge/TAVARDT-Schema.org%20Validator-5b3cf5.svg)](https://tools.tavardt.com/schema-markup-validator/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Rigorous structured data validation engine for Schema.org JSON-LD and Microdata markup, verifying entity completeness and search feature eligibility.

Engineered and maintained by the semantic intelligence and structured data team at **TAVARDT**.

***

## Semantic Validation Capabilities

* **High-Fidelity Structured Data Extraction**: Comprehensive parsing of embedded JSON-LD and Microdata entity structures.
* **Core Schema.org Classification**: Deep inspection of Organization, LocalBusiness, WebSite, Article, Product, FAQPage, and BreadcrumbList models.
* **Syntax and Compliance Verification**: Pinpoints unparseable JSON blocks, missing mandatory fields, and formatting anomalies.
* **Semantic Quality Scoring**: Standardized 0 to 100 rating with precise recommendations to maximize search feature eligibility.

***

## Installation and Execution

Requires Python 3.8 or higher with zero external dependencies.

```bash
git clone https://github.com/TAVARDT-USA/schema-markup-validator-us.git
cd schema-markup-validator-us
python schema_validator.py example.com
```

To run in automated pipelines with JSON output:

```bash
python schema_validator.py example.com -json
```
